# 실행 이력별 결과 파일 보관

열·설문 설정 저장 → **백그라운드 집계 접수** → 완료 후 **저장된 집계 결과 보기**에서 **보관 CSV / HTML / XLSX 다운로드**를 누릅니다. 각 버튼에 파일 크기와 SHA-256을 표시합니다. 설정을 바꾸거나 서버를 다시 시작해도 당시 생성한 파일을 그대로 내려받습니다. 다운로드에 원본 재파싱이나 집계 재실행은 없습니다.

기존 **선택 열 기초 집계**의 다운로드는 현재 저장 설정으로 다시 계산하는 별도 기능입니다. 현재 설정으로 새 파일을 보관하려면 새 백그라운드 작업을 접수하세요. v7 적용 전에 완료된 작업은 저장 요약만 유지하며 파일이 없는 이유를 안내합니다. 과거 파일을 현재 설정으로 소급 생성하지 않습니다.

## 결과 계약

하나의 전체 집계에서 표시용 JSON·HTML과 전체 빈도 CSV·XLSX를 만들며 원본 SHA-256·선택 버전·계산 시각·집계 작업 ID를 함께 기록합니다. CSV의 텍스트 보호·20MiB, HTML의 이스케이프/CSP·5MiB·상위 30개/긴 값 200자, XLSX의 5개 시트·명시적 텍스트·긴 값 분할·XML/압축 각각 20MiB 한도는 기존 내보내기와 같습니다. 출력 한도를 하나라도 초과하면 작업 전체가 실패하며 일부 형식만 공개하지 않습니다.

v7은 기존 테이블을 유지하고 `summary_run_artifacts`에 실행 ID·형식·바이트 크기·SHA-256·생성 시각을 추가합니다. 세 파일의 메타데이터와 완료 상태·요약·이벤트를 같은 DB 트랜잭션으로 확정합니다. 파일 본문은 DB 밖에 보관합니다.

기본 경로는 `storage/output/runs/<run-id>/summary.csv|html|xlsx`이며 `OFFICE_OUTPUT_DIR`로 변경합니다. 입력 원본 루트와 분리된 비공개 전용 디렉터리를 지정하세요. 새 디렉터리 0700·파일 0600을 적용합니다. 암호화 저장이나 Windows ACL 설정을 대신하지 않습니다. **DB와 입력 원본, 출력 파일을 함께 비공개 백업해야** 결과 파일을 복구할 수 있습니다. DB·백업·입출력 본문은 Git과 정적 웹 루트에 넣지 않습니다. 테스트는 별도의 DB·입력·출력 경로를 사용합니다.

## 게시·정리·무결성

워커가 모든 파일을 생성한 뒤 실행별 고유 임시 디렉터리에 배타적으로 기록하고 fsync합니다. 큐 관리자가 크기·해시·일반 파일 여부를 검증하고 최종 디렉터리로 원자적 rename한 뒤, lease·취소·원본/설정 버전을 재검증해 DB를 완료 처리합니다. 취소·시간 초과·정상 종료 시 워커를 종료한 다음 부분 파일을 정리합니다. DB 저장 실패 시 트랜잭션을 롤백하고 게시 파일을 제거합니다. 파일시스템과 SQLite가 하나의 트랜잭션을 이루지는 않습니다.

강제 종료로 파일과 DB가 어긋나면 큐 lease를 획득한 서버가 시작 시와 약 30초 주기로 알려진 실행의 미완료 출력·남은 임시 디렉터리를 정리합니다. 현재 워커의 임시 디렉터리, 완료 실행의 최종 파일, DB에 없는 실행/알 수 없는 이름의 경로는 보존합니다. 정리 오류는 로그에 고정 안내만 남기며 작업은 출력 오류로 실패할 수 있습니다. 관리자가 임의로 다른 파일을 출력 루트에 넣지 않도록 하세요.

다운로드는 계정·업무·첨부·실행의 소유권과 완료 상태를 검사합니다. 심볼릭 링크를 거부하고 파일 크기·SHA-256을 확인한 뒤 세션을 다시 검사합니다. 손상·분실 시 409로 차단하며 저장 요약이나 다른 정상 형식은 계속 볼 수 있습니다. 해당 파일을 자동 재생성하거나 덮어쓰지 않습니다. 완료 후 현재 설정 변경이나 원본 분실은 보관 파일 다운로드를 막지 않습니다.

## API

접두사: `/api/jobs/:id/attachments/:fileId/runs/:runId`.

| 요청 | 응답 |
| --- | --- |
| GET `/result` | `{ summary, artifacts: [{ format, size, sha256, createdAt }] }`. 이전 완료 작업은 `artifacts: []` |
| GET `/artifacts/csv` | 당시 CSV 바이트 |
| GET `/artifacts/html` | 당시 HTML 바이트, 제한 CSP |
| GET `/artifacts/xlsx` | 당시 XLSX 바이트 |

파일명은 `office-run-<run-id>.<format>`입니다. 세션·계정 검증, no-store·nosniff, 첨부 응답을 적용합니다. 비로그인/계정 전환 401, 다른 소유자/업무/첨부/실행·없는 형식/이전 작업의 없는 파일 404, 미완료 또는 보관 파일 무결성 실패 409입니다. 임의 경로·파일명·현재 설정을 다운로드 입력으로 받지 않습니다.

이력·파일 자동 삭제, 전체 디스크 사용량 상한, 운영 백업/복구 자동화는 후속 과제입니다. 작업당 제한은 전체 보관량의 상한이 아닙니다. 사용자 검토·승인, AI 호출이나 외부 발송은 이번 기능에 포함하지 않습니다.
