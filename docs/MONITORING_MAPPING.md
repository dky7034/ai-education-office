# 모니터링 지표와 원문 열 연결

첨부 미리보기에서 분석할 열을 선택한 뒤 **모니터링 지표·열 연결**에서 필요한 열을 체크합니다. 지표 종류·이름·선택 단위를 입력하고 기존 **열 선택 저장** 버튼으로 저장합니다. [자료 근거 행 확인](ROW_EVIDENCE.md)을 조회하면 원문 셀 주소·값 옆에 저장한 지표 정보를 표시합니다.

이 기능은 사람이 확인할 자료의 이름표를 연결합니다. 교육생 식별·점수화·위험 분류·임계값 판정·평가·승인·AI 호출은 하지 않습니다. 표시 단위가 %여도 0.9를 90으로 변환하거나 90을 90%로 다시 쓰지 않습니다. 판단 기준과 원문 값의 의미는 사람이 확인해야 합니다.

## 입력과 저장 범위

| 필드 | 기준 |
| --- | --- |
| index | 현재 선택한 열의 0~99 인덱스, 열마다 하나 |
| metric | attendance(출석 자료), progress(진도 자료), submission(과제 자료), reference(참고 자료) |
| label | 필수 1~60자, 사람이 정한 지표 이름 |
| unit | 선택, 최대 20자, 표시용 단위 |

문자 수는 UTF-16 단위이며 앞뒤 공백을 제거합니다. 줄바꿈·일부 제어/방향 문자·알 수 없는 필드를 거부합니다. 연결은 최대 10개이며 같은 지표 종류를 서로 다른 열에 사용할 수 있습니다. 임계값·가중치·판정식 필드는 받지 않습니다. 실제 개인정보나 비밀 값을 이름/단위에 넣지 않습니다.

지표 정보는 기존 시트·제목 행·선택 열·원본 해시·저장 버전에 묶입니다. 시트/제목 행 변경이나 열 제거 시 해당 편집 연결을 제거합니다. 저장 전이나 실패/충돌 시 기존 저장 결과를 바꾸지 않고 입력을 유지합니다. 충돌을 무시하고 자동 덮어쓰거나 자동 재전송하지 않습니다. 명시적으로 저장 상태를 다시 불러오면 미제출 편집이 초기화됩니다.

**열 선택·설문 설정과 같은 버전**을 사용합니다. 지표만 바꿔도 저장 버전이 올라가고 이전 버전의 근거 행 요청은 409입니다. 기존 대기/진행 집계는 설정 변경으로 실패할 수 있어 진행 중 작업을 확인한 뒤 저장합니다. 완료된 집계 JSON·CSV/HTML/XLSX 보관 파일·검토 대상/결정은 변경하지 않습니다. 새 지표 이름이 기존 정량 보고서의 열 이름이나 계산식을 바꾸지는 않습니다.

## API·호환과 권한

기존 `PUT /api/jobs/:jobId/attachments/:fileId/selection`의 선택적인 monitoring 배열로 저장합니다. 각 원소는 index/metric/label/unit 네 필드를 전달합니다. 단위를 표시하지 않으면 unit은 빈 문자열입니다. 소유권·원본 크기/해시·저장 버전 충돌·비동기 읽기 뒤 세션 재검증은 기존 계약을 유지합니다. 잘못된 배열/연결은 422이며 업무/첨부 권한이 없으면 404입니다. 구문·필수 선택 조건 오류는 기존 400 계약입니다.

- monitoring을 명시하면 정규화한 목록으로 교체하며, []는 연결 전체 해제입니다.
- 기존 클라이언트가 monitoring을 생략하면 같은 시트/제목 행/원본의 기존 연결 중 새 선택 열에 남는 항목만 유지합니다.
- 시트/제목 행/원본 맥락이 달라지고 배열을 생략하면 []로 초기화합니다. 이전 지표가 다른 자료에 자동으로 붙지 않습니다.

선택 응답의 monitoring은 항상 배열입니다. 근거 행 응답 cells[].mapping은 해당 열의 저장된 연결 또는 null입니다. 원문 값·공란/수식/오류·표시 생략은 기존 방식 그대로이며 지표 종류로 재분류하지 않습니다. 프런트엔드는 연결 정보도 저장 버전/선택과 대조해 잘못된 200 응답을 표시하지 않습니다. 배열 속성의 JSON 키 순서에는 의존하지 않습니다.

새 이벤트 종류나 별도 소켓은 추가하지 않습니다. 저장은 기존 selection.saved와 같은 트랜잭션이며 지표 이름/단위를 이벤트에 복사하지 않습니다. 미저장 편집 중에는 근거 행 패널을 숨기고 조회를 중단합니다. 버전 변경/파일/계정 전환 시 이전 근거 결과를 제거합니다. 읽기만으로 지표가 저장되거나 집계가 시작되지 않습니다.

## DB와 미완료 범위

스키마 v13은 column_selections에 NOT NULL·기본 '[]'인 monitoring_json 열 하나만 추가합니다. 기존 선택 버전/원본/설문·업무/집계/AI/검토 기록을 재작성하지 않습니다. 과거 집계나 검토에 지표를 소급 첨부하지 않습니다. 마이그레이션 전에 비공개 DB 백업을 만들고 기존 행 보존·실패 롤백을 확인합니다.

현재 기능은 지표·열 연결과 원문 확인 기반입니다. 교육생 식별/기록 묶기·지표 값의 해석 기준·판단 근거 부족 상태·사람의 검토/보관 정책은 후속 작업입니다. 로드맵의 교육생 모니터링 전체 항목과 완료 비율은 유지합니다.
