# 단계별 개발 로드맵

Phase 1·2와 Phase 3의 업무 저장·계정 인증·이력 복구·XLSX/CSV 첨부·미리보기·열 선택을 구현했습니다. 선택 열의 수동 누락·빈도·숫자 기초 집계·설문 척도/필수 기준과 CSV·HTML·XLSX 내보내기·백그라운드 정량 집계 큐·실행별 CSV/HTML/XLSX 보관까지 구현했습니다. Phase 3의 나머지와 Phase 4~6의 나머지는 계획입니다.

체크리스트 진행도: **38/62 (약 61%)**. 작업 수 기준이며 개발 시간 비율이 아닙니다. 영구 이벤트 재생과 정량 집계의 읽기 전용 오피스 표시를 완료했습니다. 전체 AI 업무 상태 모델·캐릭터 연결은 별도 미완료 항목입니다. 실제 AI 호출·운영 배포는 미완료입니다.
