# 분석 결과 XLSX 다운로드

집계 실행 후 **분석 결과 XLSX 다운로드**를 누릅니다. 저장 원본과 열/설문 설정 버전을 다시 검증하고 전체 데이터를 재계산해 별도 통합 문서를 생성합니다. 원본 파일·업무 상태·DB 설정을 수정하지 않으며 서버에 출력 파일을 보관하지 않습니다.

## 시트 구성

| 시트 | 내용 |
| --- | --- |
| 집계 안내 | 업무/원본 파일 ID·파일명·SHA-256·선택 버전·시트·제목 행·생성 시각(UTC)·계산/분할 기준 |
| 전체 요약 | 제목 이후 전체 행·포함 행·공란 제외 행, 설문 설정 시 유효 응답 행·기준 미충족 행 |
| 열별 집계 | 열별 일반 값·누락·수식·오류·빈도 종류 수, 숫자 건수·합계·평균·최솟값·최댓값 |
| 설문 문항 | 문항·정수 척도·필수 여부·유효/제외 사유별 건수·문항 유효값 통계 |
| 전체 빈도 | 선택 열별 모든 값과 빈도, 원문 길이, 긴 값 분할 번호 |

설문 설정이 없으면 설문 문항 시트는 제목 행만 표시하고 안내 시트에 명시합니다. 빈 숫자/문항 결과는 빈 셀로, 실제 0은 `0`으로 구분합니다. 첫 행을 고정하고 제목 행에 필터를 제공합니다. 집계 기준은 [기초 집계](BASIC_SUMMARY.md)·[설문 설정](SURVEY_SETTINGS.md)과 같으며, 기존 기초·숫자 집계는 설문 유효 행으로 필터링하지 않습니다.

이 파일은 원본의 편집본이 아닌 집계표입니다. 원본 시트·수식·서식·그림·차트·매크로를 복사하지 않습니다. AI 문장·역문항·통합 점수·개인 평가를 생성하지 않습니다.

## 셀 유형과 긴 값

원본 유래 파일명·시트명·열 제목·빈도 값, 숫자 합계/평균/최솟값/최댓값과 척도 범위는 **명시적인 텍스트 셀**입니다. `=`, `+`, `-`, `@`로 시작하는 값·URL도 수식이나 하이퍼링크로 만들지 않습니다. `01`·큰 정수·정확한 십진수를 보존하며 CSV와 달리 보호용 작은따옴표를 추가하지 않습니다. 건수·항목/조각 번호·원문 문자 수는 안전한 정수의 숫자 셀입니다.

Excel 셀 길이 제한을 지키기 위해 빈도 값은 최대 **32,000 UTF-16 단위**로 분할합니다. 이모지의 서로게이트 쌍은 나누지 않습니다. **같은 열·항목 번호**의 `값`을 `분할 조각 번호` 순서대로 이어 붙이면 집계 원문 전체입니다. `건수`와 `원문 문자 수`는 **첫 조각에만** 기록하므로 이어지는 행의 빈 건수를 0건짜리 별도 항목으로 보거나 빈도를 중복 합산하지 마세요. 원문 문자 수는 앞뒤 공백 제거 후 JavaScript UTF-16 길이입니다.

전체 빈도는 화면의 상위 30개·200자 표시 한도 없이 내보냅니다. 열 제목은 기존 집계의 120자 표시 한도를 따르므로 열 위치로 구분합니다. XML 특수 문자는 이스케이프하고 CR·XML 금지 제어문자는 OOXML `_xHHHH_` 표기로 인코딩합니다. 원래 이 표기와 같은 문자열도 별도로 보호합니다. 일부 XML/엑셀 파싱 라이브러리는 OOXML 이스케이프를 해제하지 않고 그대로 반환할 수 있습니다.

## 제한·권한·API

`POST /api/jobs/:id/attachments/:fileId/summary.xlsx`, JSON `{ "revision": 1 }`을 사용합니다. 유효한 세션·업무 소유권·동일 Origin·`X-Office-Request: 1`이 필요하며 UI는 `X-Office-Account`도 전송합니다. 임의 열·설문 설정·경로·원본 해시를 요청 본문에서 받지 않습니다.

입력 형식/행/열/셀 한도는 기존 집계와 동일합니다. 생성하는 XML 전체와 최종 압축 파일은 **각각 20MiB** 이하입니다. 초과·잘린 집계·셀/시트 한도 오류는 부분 파일 대신 422 JSON으로 반환합니다. 설정 미저장·오래된 버전·원본 무결성 오류는 409, 다른 소유자는 404, 인증 실패는 401, 잘못된 본문은 400입니다.

서버는 생성 전 원본 크기·SHA-256·선택 버전을 검사하고 비동기 ZIP 생성 후 세션·선택 버전을 다시 확인합니다. 응답은 공식 XLSX MIME, `attachment; filename="office-summary-<fileId>.xlsx"`, `no-store`, `nosniff`를 사용합니다. 파일명은 원본 이름을 헤더에 직접 넣지 않습니다. 출력 파일을 영구 저장하거나 새로운 DB 테이블을 만들지 않으므로 XLSX 출력 자체는 DB 스키마를 변경하지 않습니다.

ZIP 작성에는 기존 테스트용 `yazl` 3.3.1을 런타임 의존성으로 승격해 사용합니다. 외부 리소스·매크로·수식·외부 링크 관계를 생성하지 않습니다. 전체 입력 처리/다운로드의 공개 운영용 작업 격리·동시성 제한은 후속 과제입니다.
