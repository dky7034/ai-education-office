# 설문 문항·척도·유효 응답 기준

파일 미리보기에서 분석할 열을 고른 뒤 **설문 문항·척도 설정**에서 문항으로 사용할 열을 지정합니다. 문항명은 해당 열의 제목을 사용합니다. 문항마다 척도 최솟값·최댓값과 필수 응답 여부를 설정하고 **열 선택 저장**을 누른 다음 **전체 데이터 집계**를 실행합니다. 설정 저장만으로 집계나 AI가 실행되지는 않습니다.

## 설정 범위와 저장

- 선택한 열만 문항으로 지정할 수 있으며 열당 한 문항입니다. 정수 척도는 -1,000,000~1,000,000 범위, 최솟값 ≤ 최댓값이며 양 끝값을 포함합니다. 기본값은 1~5·필수입니다. 같은 값으로 양 끝을 지정할 수도 있습니다.
- 열 선택·시트·제목 행·설문 문항 설정을 하나의 선택 버전으로 저장합니다. 변경 중에는 기존 집계 결과를 제거합니다. 열을 해제하면 해당 문항 설정도 제거합니다. 시트·제목 행 변경은 해당 화면에서 일치하는 저장 설정만 다시 불러옵니다.
- 다른 화면에서 먼저 저장하면 409로 거부합니다. 저장 상태 다시 불러오기를 눌러 최신 설정을 확인하세요. 새로고침·서버 재시작 후에도 설정을 복원합니다.
- 설정하지 않으면 기존 기초·숫자 집계만 제공합니다. 문항을 전부 해제하고 저장하면 설문 집계를 끕니다.

## 행 전체의 유효 응답 기준

기초 집계의 **집계 포함 행**을 기준으로 검사합니다. 선택 열이 모두 공란인 행은 먼저 제외합니다. 나머지 행에서 다음 조건을 모두 만족해야 유효 응답 행입니다.

1. 필수 문항마다 유효값이 있습니다.
2. 선택 문항은 공란 또는 유효값이며, 잘못된 값은 없습니다.
3. 최소 한 문항에 유효값이 있습니다. 모든 문항이 공란이고 다른 선택 열에만 값이 있는 행은 기준 미충족입니다.

유효 응답 행 + 기준 미충족 행 = 집계 포함 행입니다. 이 숫자는 고유 응답자 수가 아니며 중복 응답·개인 식별·실제 설문 제출 여부를 판정하지 않습니다. 문항으로 지정하지 않은 열의 값은 설문 기준에 영향을 주지 않습니다. 기존 전체 빈도·숫자 기초 집계는 이 기준으로 필터링하지 않습니다.

## 문항별 집계

각 문항은 모든 집계 포함 행을 대상으로 다음 중 하나로 분류합니다.

| 분류 | 기준 |
|---|---|
| 유효값 | 숫자 표기로 읽을 수 있고 정수이며 설정 척도 안에 있음 |
| 누락 | 공란. 필수 문항이면 행 전체도 기준 미충족 |
| 수식 제외 | XLSX 실제 수식. 캐시 결과도 사용하지 않음 |
| 오류 제외 | XLSX 오류 셀 |
| 숫자 아님 | 문자·통화·퍼센트·쉼표·CSV 수식 모양 등 |
| 정수 아님 | 지원 숫자 범위 안의 소수. 예: 2.5 |
| 범위 밖 | 숫자 처리 한도 초과 또는 정수값이 설정 척도 밖 |

각 분류 건수 합은 집계 포함 행 수입니다. 수식·오류·공란을 먼저 구분하고, 나머지는 숫자 여부 → 숫자 처리 한도 → 정수 여부 → 척도 범위 순으로 판정합니다. 예를 들어 척도 1~5에서 6.5는 ‘정수 아님’, 6은 ‘범위 밖’입니다. `01`, `1.0`, `1e0`은 모두 정수 1로 인정하지만 원본 빈도는 합치지 않습니다. 숫자 파싱 한도는 [숫자 기초 집계](BASIC_SUMMARY.md)를 따릅니다.

문항별 유효값의 합계·평균·최솟값·최댓값을 계산합니다. **다른 문항 때문에 행 전체가 기준 미충족이어도 해당 문항의 유효값에는 포함**합니다. 평균 분모는 해당 문항 유효값 건수이며 소수점 이하 최대 6자리 반올림을 적용합니다. 유효값이 없으면 `null`/대시/빈 칸으로 표시합니다.

숫자 모양 식별자·XLSX 날짜 저장값도 척도와 일치하면 통과할 수 있습니다. 문항 열은 사용자가 확인해야 합니다. 복수 선택·자유 서술 자동 분류·역문항·척도 환산·문항 통합 점수·중복 응답 제거·행별 사유 목록·AI 해석은 이번 기능에 포함하지 않습니다.

## API·다운로드·권한

기존 `PUT /api/jobs/:id/attachments/:fileId/selection`에 `questions` 배열을 추가합니다.

```json
{
  "sheetId": "csv",
  "headerRow": 1,
  "columns": [0, 1],
  "questions": [
    { "index": 0, "min": 1, "max": 5, "required": true },
    { "index": 1, "min": 1, "max": 5, "required": false }
  ],
  "revision": 0
}
```

`questions` 생략 또는 `[]`는 설문 설정 없음으로 저장합니다. 이전 API 클라이언트가 설정을 생략해 다시 저장하면 설문 설정도 초기화되므로 최신 `questions`를 함께 전송해야 합니다. 잘못된 문항·중복·미선택 열·범위·추가 필드는 422, 기존 요청 형식 오류는 400입니다. 소유권·동일 Origin·전용 헤더·원본 해시 검사는 유지합니다.

기존 세 집계 API는 `{ "revision": 1 }`만 받습니다. JSON에는 `survey: null` 또는 `{ validRows, invalidRows, questions }`가 추가됩니다. 문항 결과에는 설정·열 정보·각 분류 건수와 `sum`, `mean`, `minValue`, `maxValue`가 포함됩니다. 계산값은 정밀도 보존을 위해 문자열/null입니다. CSV는 기존 8열 구조에 `설문 기준`, `설문 전체`, `설문 설정`, `설문 문항` 구역을 추가합니다. HTML에도 같은 설정·기준·결과를 표시합니다. CSV 텍스트 보호·HTML 이스케이프·CSP·출력 한도는 유지합니다.

v5 마이그레이션은 기존 `column_selections`에 기본값 `[]`의 `questions_json` 열만 추가합니다. 기존 계정·업무·이벤트·첨부·열 선택·버전·원본 해시는 보존합니다. DB와 첨부 원본은 함께 백업해야 합니다. 결과 파일은 서버에 저장하지 않습니다.

같은 저장 설정으로 [분석 결과 XLSX 다운로드](XLSX_EXPORT.md)도 지원합니다. 전체 빈도와 긴 값 분할·명시적 텍스트 셀·숫자/설문 통계를 5개 시트로 제공합니다.
