# 저장 설문 결과의 요약 메일 초안

완료된 백그라운드 설문 집계 결과에서 **설문 요약 메일 초안 TXT 다운로드**를 선택합니다. 저장된 통계를 정해진 문장으로 옮긴 규칙 기반 초안이며 AI 생성·메일 발송·승인 기능이 아닙니다. 제품용 AI 설정이 없어도 사용할 수 있습니다.

## 내용과 계산 기준

- 제목·검수 필요 표시·전체/집계 포함/제외 행 수·설문 기준 유효/미충족 행 수를 포함합니다. 행 수를 고유 응답자 수로 부르지 않습니다.
- 문항별 정수 척도·필수 여부·유효값/누락/수식/오류/비숫자/비정수/범위 밖 건수와 유효값 합계·평균·최솟값·최댓값을 사용합니다. 평균은 저장된 십진 문자열을 그대로 사용하며 소수점 이하 최대 6자리 반올림 기준을 안내합니다.
- 문항 통계는 행 전체의 유효 여부와 별개인 각 문항의 모든 유효값 기준입니다. 어떤 행의 다른 문항이 잘못돼도 해당 문항의 유효값은 포함될 수 있습니다. [설문 설정](SURVEY_SETTINGS.md)의 기준을 유지합니다.
- 유효값 0개인 문항은 계산 불가로 표시하고 0점으로 대체하지 않습니다. 전체 공란만 있는 자료도 포함/제외 행과 유효값 없음으로 안내합니다. 설문 문항이 없는 일반 기초 집계에서는 초안 버튼을 표시하지 않고 API도 409입니다.
- 개별 응답값·빈도 값·업무 지시문·검토 의견·수신자 주소를 복사하지 않습니다. 시트/문항 제목에는 개인정보가 포함될 수 있어 수신자·공유 범위와 함께 검수해야 합니다. 만족도·성과·원인에 대한 해석 문장은 만들지 않습니다.

초안 하단에는 업무/첨부/실행 ID, 저장 선택 버전·집계 시각, 원본 해시와 현재 저장 집계 JSON의 SHA-256을 남깁니다. 현재 열/설문 설정이 바뀌어도 과거 실행 결과로 작성하며 새 집계를 시작하지 않습니다. 동일한 저장 결과에서는 같은 바이트를 생성하고 다운로드 시각은 삽입하지 않습니다.

## 파일과 권한

`GET /api/jobs/:jobId/attachments/:fileId/runs/:runId/mail-draft`

로그인한 소유자의 첨부·완료 실행만 허용하며 쿼리 조건을 받지 않습니다. 미로그인 401, 다른 계정/업무/첨부/실행 404, 쿼리 400, 미완료·설문 미설정·손상된 JSON/필요 필드/행·문항 건수, 저장 JSON과 실행 메타데이터의 버전/원본 해시 불일치는 409입니다. 오류 때 부분 파일을 보내지 않습니다.

출력은 `text/plain; charset=utf-8`와 attachment disposition, `office-survey-mail-<runId>.txt` 이름입니다. UTF-8 BOM·CRLF를 사용하며 최대 128KiB입니다. HTML·EML·mailto 링크나 첨부 실행 코드를 생성하지 않습니다. 원본 유래 제목은 한 줄로 정리하고 따옴표로 감싸 최대 160 Unicode 문자 이후 표시 생략을 알립니다. 일부 제어/방향 문자와 줄바꿈을 제거하고 정상 서로게이트 쌍을 자르지 않습니다.

동기 메모리 생성이며 비동기 파일 읽기나 외부 호출 없이 반환합니다. 기존 인증·계정 헤더·소유권·no-store·nosniff 정책을 적용합니다. 화면은 중복 클릭을 막고 MIME을 확인하며 실패 후 명시적으로 다시 다운로드할 수 있습니다. 열린 결과·미제출 검토 의견은 유지합니다.

## 보관·검토와의 차이

이 파일은 현재 저장 JSON에서 내려받을 때 만드는 파생 초안입니다. 원본을 다시 읽거나 AI에 보내지 않고 결과 파일을 서버 디스크에 추가하지 않습니다. 기존 CSV/HTML/XLSX 3종 보관·해시·검토 대상·검토 결정·이벤트 커서·스키마 v11을 바꾸지 않습니다. 과거 실행에 네 번째 보관 파일을 소급 추가하지 않습니다.

초안 해시는 현재 JSON의 식별에 쓰이며 과거 승인 대상과의 일치, 보관 파일/원본의 현재 무결성, 통계 내용의 진위를 증명하지 않습니다. 기존 결과물 검토 화면에서 유효성을 별도로 확인합니다. 초안을 다운로드했다고 승인됐거나 발송됐다고 표시하지 않습니다. 공유할 문구와 수치·대상은 사람이 검수합니다.

이 기능으로 설문 정량 집계·분석 XLSX·HTML 요약 보고서·규칙 기반 메일 초안 흐름을 제공합니다. AI 해석·개인별 판단·자동 발송·조직 결재는 포함하지 않습니다.
