# 원본 자료의 근거 행 확인

첨부 미리보기에서 시트·제목 행·선택 열을 저장한 뒤 **자료 근거 행 확인**에 행 번호를 입력합니다. 첫 20행 미리보기 밖의 행도 원본 파일에서 다시 읽어 확인합니다. 교육생 모니터링을 위한 자료 확인 기반이며 사람에 대한 평가·분류·자동 판단을 하지 않습니다. 근거가 충분한지는 사람이 별도로 확인합니다.

## 범위와 표시

- 저장한 시트·선택 열만 조회합니다. 조회 시 원본 크기/해시와 저장 선택 버전을 확인하고, 비동기 원본 읽기 뒤 로그인·소유권/선택 버전을 다시 확인합니다. 저장하지 않은 선택을 편집 중이면 패널을 숨기고 열린 결과를 제거합니다.
- 행 번호는 제목 행 다음부터 파일의 마지막 저장 행까지, 최대 20,000입니다. CSV는 따옴표 안 줄바꿈을 포함한 논리 레코드 번호이며 텍스트 편집기의 줄 번호와 다를 수 있습니다. XLSX는 시트의 실제 행 번호입니다.
- XLSX에서 중간 행 요소가 생략된 번호는 rowPresent=false와 함께 공란으로 표시합니다. 파일 범위 밖의 번호를 빈 행으로 추측하지 않습니다.
- 셀 주소·열 제목·저장값/공란/수식/셀 오류를 구분합니다. 공백 문자만 있는 값도 공란으로 표시합니다. XLSX 수식은 계산하지 않고 캐시 값 대신 계산하지 않음 표시를 사용합니다. 수식처럼 보이는 CSV 문자열은 일반 텍스트입니다. 숫자/날짜 서식은 변환하지 않고 기존 파서의 저장값 표현을 사용합니다. 숨김 시트/행/열도 포함될 수 있습니다.
- 셀은 최대 2,000 Unicode 코드포인트까지 표시하고 생략을 알립니다. 전체 내용은 권한 있는 원본 다운로드로 확인합니다. 응답 최대 1MiB, 기존 파일 5MiB·20,000행·100열·100,000셀 한도를 유지합니다. 요청한 행 이후도 전체 파일을 검사해 한도를 초과한 파일의 일부만 제공하지 않습니다.
- 업무/첨부·원본 SHA-256·선택 버전·시트·제목 행·자료 행·열 주소를 함께 표시합니다. HTML 모양 내용은 일반 텍스트로만 보여주며 수식·매크로·외부 연결을 실행하지 않습니다.

이 화면은 조회 시 읽은 바이트의 해시를 확인한 스냅샷입니다. 외부 파일 변조를 실시간 탐지하거나 이전 검토·판정의 유효성을 증명하지 않습니다. 변경 여부는 다시 조회해야 합니다. 기존 집계나 보관 결과를 재생성하지 않습니다.

## API와 권한

`GET /api/jobs/:jobId/attachments/:fileId/evidence?revision=<저장 버전>&row=<행 번호>`

두 쿼리만 한 번씩 지정합니다. 잘못된/누락/중복 조건·행 20,000 초과는 400, 미로그인/계정 헤더 불일치는 401, 다른 계정/업무/첨부는 404입니다. 저장 선택이 없거나 변경됐거나 원본 무결성 실패는 409, 제목 행/없는 자료 행·없는 선택 열·파일 파싱/처리 한도 오류는 422입니다. 오류 응답에 부분 자료를 넣지 않습니다. 기존 no-store·nosniff·동일 계정 정책을 사용합니다.

응답 evidence에는 jobId/fileId/revision/sourceHash/sheetId/sheetName/headerRow/rowNumber/totalRows/rowPresent와 선택 열의 cells를 담습니다. cells의 kind는 value/blank/formula/error, truncated는 표시 생략 여부입니다. 프런트엔드는 파일·계정 범위와 요청한 버전/해시/시트/제목 행/자료 행·선택 열·표시 한도를 검사해 잘못된 200 응답도 표시하지 않습니다.

조회는 명시적 버튼의 GET뿐입니다. 입력 변경·저장 버전/파일/계정 전환 때 결과를 제거하고 이전 요청을 중단해 늦은 응답을 버립니다. 실패 후 행 번호를 유지해 재조회하며 새 업무 입력을 바꾸지 않습니다. 새 WebSocket·자동 반복 조회·POST는 추가하지 않았습니다.

## 구현 경계

DB 스키마 v12·열 선택·원본·집계/AI/검토·업무 상태·이벤트를 변경하지 않습니다. 원문 행을 서버에 추가 보관하거나 AI/외부 서비스에 보내지 않고 평가·승인·발송 기록도 만들지 않습니다. 실제 교육생 자료는 테스트에 넣지 않았습니다.

이번 범위는 모니터링의 근거 행 조회 기반입니다. 교육생 식별/열 매핑·지표와 판단 기준·근거 부족 상태·사람의 검토/보관 정책은 후속 작업이며, 로드맵의 교육생 모니터링 전체 항목은 미완료로 유지합니다.
