# 선택 열 기초 집계

로그인 → 저장된 업무 상세 → 첨부 미리보기 → 시트·제목 행·분석할 열 저장 → **전체 데이터 집계** 순서로 실행합니다. 저장하지 않은 선택이 있거나 다른 시트·제목 행을 보는 중이면 먼저 열 선택을 저장해야 합니다.

이 기능은 결정적 코드로 계산하는 정량 기초 집계입니다. AI 호출·요약·평가 점수 생성·발송은 하지 않습니다. 원본과 선택 설정, 업무 상태·접수 이벤트는 변경하지 않습니다. 캐릭터는 계속 별도의 시뮬레이션입니다.

## 집계 기준

- 저장한 시트의 제목 행 다음부터 기록된 마지막 행까지 검사합니다. 미리보기의 20행을 넘어 전체 데이터를 읽으며, XLSX의 희소 행 사이 공란도 물리적 행 범위에 포함합니다.
- **선택한 열이 모두 공란인 행은 제외**합니다. 선택하지 않은 열에만 값이 있는 행도 제외합니다. 나머지가 ‘집계 포함 행’입니다. 포함 행 수는 실제 응답자 수나 유효 설문 응답 수를 뜻하지 않습니다.
- 포함된 행에서 열마다 일반 값·누락·수식 제외·오류 제외를 셉니다. 각 열에서 네 건수의 합은 포함 행 수와 같습니다. 빈 행을 제외한 뒤의 누락이므로 ‘전체 행의 빈 칸 수’와는 다릅니다.
- 일반 값은 앞뒤 공백을 제거해 비교합니다. 대소문자와 숫자 표기는 유지합니다. 예: `1`, `01`, `1.0`은 서로 다른 값이며 `0`은 공란이 아닙니다. 내부 줄바꿈·공백·유니코드 표기를 임의로 합치지 않습니다.
- XLSX 실제 수식·오류 셀은 빈도와 일반 값에서 제외하고 별도 건수로 표시합니다. 수식/오류만 있는 행은 공란이 아니므로 포함합니다. 수식은 계산하지 않으며 캐시 결과도 집계하지 않습니다. 수식 안내 문구와 같은 모양의 **일반 문자열**은 정상적인 값으로 셉니다.
- CSV의 `=1+1` 같은 값은 실행하지 않고 문자열로 셉니다. HTML·URL도 실행하거나 링크로 변환하지 않습니다.
- XLSX 숫자·날짜는 서식 적용 전의 원본 저장값, 불리언은 TRUE/FALSE 표시 문자열로 셉니다. 셀 유형이 달라도 같은 표시 문자열이면 같은 일반 값으로 셉니다. 숨김 시트·행·열도 포함될 수 있습니다. 숫자 모양의 일반 값에는 아래 숫자 기초 집계를 제공합니다. 표준편차·척도 점수·개인별 평가는 제공하지 않습니다.

## 결과 표시와 제한

전체 행 / 포함 행 / 선택 열 공란으로 제외한 행, 열별 네 건수와 서로 다른 일반 값의 수를 표시합니다. 값별 빈도는 건수 내림차순, 동률이면 문자열 순으로 정렬해 **상위 30개**를 표시합니다. 나머지 값 종류 수·빈도 합계도 표시하므로 상위 빈도 합계와 나머지 합계를 더하면 일반 값 건수가 됩니다.

긴 값은 표시만 200자로 줄입니다. 집계에서는 원문 전체를 비교하므로 같은 200자 앞부분을 가진 서로 다른 값도 합치지 않습니다. 화면에서 비슷하게 보이는 잘린 항목은 원본 파일에서 구분해 주세요. **전체 빈도 CSV 다운로드**는 화면의 30개 제한·200자 표시 제한 없이 전체 값과 빈도를 내보냅니다. 화면 열 제목의 120자 제한은 CSV에도 적용하며 원본 열 위치로 구분합니다.

파일 처리 한도는 미리보기와 같은 20,000행·100열·100,000셀입니다. XLSX 공유 문자열은 최대 100,000개입니다. 한도를 넘으면 422 오류로 거부하며 부분 결과를 전체 결과처럼 보여주지 않습니다. 업로드 한도·지원 형식·서식 재현 한계는 [첨부 안내](ATTACHMENTS.md)와 [미리보기 안내](FILE_PREVIEW.md)를 따릅니다.

동기 집계 결과는 계산 시각·원본 해시·선택 버전과 연결해 반환하며 DB에 별도로 저장하지 않습니다. 새로고침이나 미리보기 닫기 후에는 다시 실행합니다. 선택을 수정하면 기존 결과를 화면에서 제거합니다. 실행 시점에 다른 화면에서 선택을 바꿨다면 409를 반환하므로 저장 상태를 다시 불러오세요.

## API와 권한

`POST /api/jobs/:id/attachments/:fileId/summary`

JSON 본문은 `{ "revision": 1 }`처럼 저장된 선택 버전만 받습니다. 임의 열·시트·원본 경로·해시를 지정할 수 없습니다. 유효한 세션, `X-Office-Request: 1`, 동일 Origin이 필요하며 UI는 `X-Office-Account`도 전송합니다.

서버가 저장한 선택과 원본 크기·SHA-256을 확인한 뒤 계산합니다. 결과 반환 전 세션·선택 버전을 다시 확인합니다. 다른 계정은 404, 비로그인·계정 전환은 401, 원본 변조·선택 미저장·오래된 선택 버전은 409, 잘못된 요청은 400, 파싱·처리 한도는 422입니다. 응답은 비캐시이며 파일 내용·집계 값·자격 증명을 로그로 출력하지 않습니다.

현재 파싱·집계는 제한된 입력에 대해 Node 프로세스에서 수행합니다. 공개 운영용 실행 격리·시간 제한·전역 동시성·전체 저장량 제한은 후속 과제입니다. 실제 개인정보 파일은 넣지 않습니다.


## 전체 빈도 CSV 다운로드

집계 실행 후 **전체 빈도 CSV 다운로드**를 누릅니다. 서버가 같은 저장 버전과 원본 해시를 다시 검증하고 재계산하므로 생성 시각은 화면 집계 시각과 다를 수 있습니다. 다른 계정·오래된 버전·변조 원본은 다운로드할 수 없습니다.

CSV는 UTF-8 BOM·CRLF이며 모든 필드를 큰따옴표로 감쌉니다. 한글·쉼표·큰따옴표·셀 내 줄바꿈을 보존합니다. 업무/파일 ID·원본 파일명·SHA-256·선택 버전·시트·제목 행·생성 시각, 전체/열별 건수, 계산 기준과 **전체 값별 빈도**를 포함합니다. 출력 최대 20MiB이며 초과하면 부분 파일 대신 422 오류를 반환합니다. 원본이나 DB에 결과 파일을 추가하지 않습니다.

스프레드시트 수식 주입을 막고 숫자처럼 보이는 텍스트를 보존하기 위해 원본 파일명·시트·열 제목·빈도 값 등 텍스트 앞에 작은따옴표(`'`)를 추가합니다. 이는 내보낸 표현만 바꾸며 원본은 변경하지 않습니다. 일부 CSV 뷰어에서는 작은따옴표가 그대로 보입니다. 프로그램에서 읽을 때 이 보호 문자를 인지하세요. 건수는 서버에서 계산한 숫자로 내보냅니다.

API: `POST /api/jobs/:id/attachments/:fileId/summary.csv`, 본문 `{ "revision": 1 }`. 기존 집계 API와 같은 세션·계정·Origin·사용자 정의 헤더·선택 버전 검사를 적용합니다. 정상 응답은 `text/csv; charset=utf-8`와 attachment 헤더, 비캐시·nosniff 정책을 사용합니다. 오류는 JSON입니다.

[실제 화면 캡처](SCREENSHOTS.md) · [실제로 다운로드한 합성 CSV 예시](examples/summary-sample.csv)


## 빈도 그래프와 인쇄용 HTML 보고서

집계 화면의 막대 그래프는 열별 **일반 값 전체**를 분모로 한 비율이며 실제 건수와 소수점 한 자리 비율을 함께 표시합니다. 누락·XLSX 수식·오류는 분모에서 제외합니다. 상위 최대 10개만 그리므로 표시 비율 합계가 100%보다 작을 수 있고 반올림 차이가 있습니다. 일반 값이 없으면 그래프를 표시하지 않습니다. 업무 진행률이나 교육생 평가가 아닙니다.

**인쇄용 HTML 보고서 다운로드**는 원본 정보·SHA-256·업무/파일 ID·선택 버전·생성 시각(UTC), 집계 기준·전체/열별 건수·그래프·상위 30개 빈도·나머지 합계를 포함합니다. 원본 전체에서 계산하지만 표에는 상위 30개, 긴 값에는 200자 표시 한도를 적용합니다. 전체 빈도·전체 값은 CSV 다운로드로 확인하세요. 보고서는 생성 시점의 결과이며 앱의 이후 변경을 반영하지 않습니다.

파일을 브라우저에서 열고 인쇄 메뉴에서 인쇄 또는 PDF 저장을 선택합니다. 외부 폰트·이미지·스크립트·네트워크 요청 없이 동작하는 단일 파일입니다. 원본의 HTML·URL은 텍스트로만 표시하며 HTML 특수 문자를 이스케이프하고 CSP로 스크립트·외부 리소스·폼을 차단합니다. 인쇄 시 페이지 여백·배율은 브라우저 설정에 따라 달라질 수 있습니다.

API: `POST /api/jobs/:id/attachments/:fileId/summary.html`, JSON `{ "revision": 1 }`. 기존 집계/CSV와 같은 세션·소유권·Origin·원본 해시·선택 버전 재검증을 거칩니다. `text/html; charset=utf-8`, 안전한 고정 패턴 파일명 `office-summary-<fileId>.html`의 attachment·no-store·nosniff·CSP 헤더로 응답합니다. 5MiB를 넘으면 부분 파일 대신 422 JSON 오류를 반환합니다. DB·원본·업무 상태를 수정하거나 서버에 보고서를 보관하지 않습니다.

## 숫자 기초 집계

선택한 각 열의 **일반 값 중 숫자로 인정한 부분집합**을 계산합니다. 숫자 인정·숫자 아닌 일반 값·숫자 범위 초과 건수를 함께 표시하며 세 건수의 합은 일반 값 건수입니다. 누락·XLSX 수식·오류는 숫자 건수와 평균 분모에 포함하지 않습니다. 공란 행 제외·빈도 계산 기준은 유지합니다.

- 앞뒤 공백 제거 후 부호·소수점·십진 지수 표기를 허용합니다. 예: `0`, `+01`, `-.5`, `1.`, `1e2`, `-2E-1`.
- 쉼표·통화·퍼센트·날짜·내부 공백은 변환하지 않습니다. `1,000`, `₩100`, `10%`, `2026-10-22`, `TRUE`, `NaN`, `Infinity`, `0x10`, `=1+1`은 숫자가 아닌 일반 값입니다. 원래 빈도에서는 그대로 유지합니다.
- 정규화 후 정수부·소수부 각각 100자리까지 지원합니다. `1e99`, `1e-100`은 지원하고 `1e100`, `1e-101`은 범위 초과로 제외합니다. 정수부의 불필요한 앞 0과 소수부 끝 0은 자리 제한에 포함하지 않습니다. 합계는 입력보다 자릿수가 늘어날 수 있습니다.
- 내부 계산은 BigInt 기반 십진 고정소수점입니다. `0.1 + 0.2`는 `0.3`으로 계산하며 큰 정수의 정밀도를 보존합니다. 합계·최솟값·최댓값은 반올림하지 않고, 평균은 숫자 인정 건수로 나눠 소수점 이하 최대 6자리로 반올림합니다. 7번째 자리가 5 이상이면 절댓값이 커지는 방향으로 처리하며 불필요한 끝 0과 음수 0을 제거합니다. 작은 평균이 `0`으로 반올림될 수 있습니다.
- 숫자로 인정한 값이 없으면 합계·평균·최솟값·최댓값은 API `null`, 화면·HTML `—`, CSV 빈 칸으로 표시합니다. 실제 숫자 0의 결과와 구분합니다.

XLSX 날짜·시간의 숫자 저장값과 숫자 모양의 식별자·텍스트도 포함될 수 있습니다. 서식·업무 의미로 숫자 열을 자동 판정하지 않습니다. 이 결과를 유효 응답 수·설문 척도 점수·교육생 평가로 간주하지 마세요. 설문 문항·척도·유효 응답 행 기준은 [설문 설정 안내](SURVEY_SETTINGS.md)의 별도 집계로 제공합니다. 일반 숫자 열의 업무 의미를 자동 판정하지 않습니다.

API의 열별 `numeric` 필드는 `{count, nonNumericCount, outOfRangeCount, sum, mean, min, max}`입니다. 합계·평균·최솟값·최댓값은 JSON 정밀도 손실을 막기 위해 문자열 또는 `null`로 반환하며 세 건수는 숫자입니다. 세 집계 API(JSON·CSV·HTML)가 같은 계산을 사용하며 권한·원본 해시·선택 버전 검사를 유지합니다. CSV에 추가된 `숫자 집계` 구역은 건수를 숫자로, 계산 결과를 작은따옴표로 보호한 텍스트로 내보냅니다. 기존 8열 구조·전체 빈도는 유지합니다. DB 마이그레이션·원본 수정·결과 보관은 없습니다.

[실제 숫자 집계 화면](SCREENSHOTS.md) · [숫자 집계 CSV 예시](examples/numeric-summary-sample.csv) · [숫자 집계 HTML 예시](examples/numeric-summary-sample.html)

설문 설정을 저장하면 [설문 기준 집계](SURVEY_SETTINGS.md)가 별도로 추가됩니다. 기존 기초·숫자 집계는 설문 유효 행 기준으로 필터링하지 않습니다.

같은 저장 설정으로 [분석 결과 XLSX 다운로드](XLSX_EXPORT.md)도 지원합니다. 전체 빈도와 긴 값 분할·명시적 텍스트 셀·숫자/설문 통계를 5개 시트로 제공합니다.

별도로 접수하는 [백그라운드 집계](BACKGROUND_SUMMARY.md)는 완료 요약 JSON과 실행 이력을 DB에 저장합니다. 기존 동기 집계/내보내기와 구분합니다.
